Project Title: Carnival City Automated Ticketing & Auditing Engine

The Problem: Movie theaters receive messy, raw text file updates of bookings and require zero-overhead terminal applications to generate instant, sorted financial audits.

Key Features Implemented:

Custom Tokenizer: Parses unstructured data streams character-by-character.

Data Masking: Built-in data security compliance that dynamically intercepts sensitive customer data (Reference numbers masked with XX).

Memory Management: Handled via standard Arrays of custom Object Classes (Client).

Defensive Programming: Enforced run-time integrity constraints utilizing custom memory assertion flags.

How to Run: Include the brief standard compilation lines (g++ -std=c++11 src/main.cpp -o booking_system).
